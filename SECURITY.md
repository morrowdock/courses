# Security

Only the latest reviewed staging commit is supported; no public release exists. Report vulnerabilities privately to the repository owner using the existing private project channel. Do not file public exploit or credential reports. Include affected version, reproduction with synthetic data, impact and reply route. Maintainers triage, coordinate remediation and agree on disclosure timing. No response-time guarantee is claimed.

Release gate: configure GitHub private vulnerability reporting where available and designate a monitored confidential address and security owner before publication. Never include real credentials or learner data in reports.
