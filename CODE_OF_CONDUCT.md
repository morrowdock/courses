# Code of conduct

Treat contributors respectfully; no harassment, discrimination, threats, sexualized conduct, doxxing or retaliation. Maintainers may remove content, restrict access or suspend participants, proportionate to severity; offer an appeal to an uninvolved maintainer where possible.

Private staging: report privately to the repository owner through the existing private project channel. Do not post sensitive reports in issues. Before release, an approved confidential reporting address and enforcement owner must replace this staging route. Public release is blocked until both are assigned.
