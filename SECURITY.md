# Security

Only the latest reviewed staging commit is supported; no public release exists. Report vulnerabilities privately to [hello@morrowdock.app](mailto:hello@morrowdock.app), the owner-approved security contact. Do not file public exploit or credential reports. Include affected version, reproduction with synthetic data, impact and reply route. Maintainers triage, coordinate remediation and agree on disclosure timing. No response-time guarantee is claimed.

Release gate: configure GitHub private vulnerability reporting where available and confirm a security owner, mailbox monitoring and response ownership before publication. Never include real credentials or learner data in reports.
